# AAA RV Website — GitHub Pages Test

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open the repository's **Settings** and choose **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will display the website address after the first deployment finishes.
The page is fully static and does not require a build command.
